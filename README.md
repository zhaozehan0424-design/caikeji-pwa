# 复材记

复合材料工艺与界面学习题库，参考 `caikeji-pwa` 的本地 PWA 结构制作。

## 内容

- 108 道核心简答题，保留 145 道原题来源编号
- 108 道判断巩固题
- 54 道单选巩固题
- 108 个知识背诵卡片
- P1 必背冲刺：61 组高频骨架题，首页默认优先抽取
- 今日学习、全量题库、知识背诵、错题本、学习统计、本地进度导入导出
- 公式中的下标和上标使用可读的数学排版

## 启动

在当前目录运行：

```powershell
python -m http.server 5173
```

然后打开 <http://localhost:5173>。

也可以在项目上一级目录运行：

```powershell
python -m http.server 5173 -d "复合材料题库PWA"
```
